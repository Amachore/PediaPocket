# Assets Folder

This folder should contain your app's image assets.

## Required Assets (for production)

Create the following placeholder assets or replace with real ones:

- **icon.png** (1024x1024px) - App icon
- **splash.png** (2048x2732px) - Splash screen
- **adaptive-icon.png** (1024x1024px) - Android adaptive icon
- **favicon.png** (48x48px) - Web favicon

## Quick Setup for Development

For rapid prototyping, you can use placeholders:

1. Use any 1024x1024 image as `icon.png`
2. Use any large image as `splash.png`
3. Copy `icon.png` to `adaptive-icon.png`
4. Use a small version as `favicon.png`

Or download free assets from:
- https://www.flaticon.com
- https://unsplash.com
- https://www.freepik.com

**Note**: The app will work without these assets in Expo Go, but they are required for building standalone apps.
